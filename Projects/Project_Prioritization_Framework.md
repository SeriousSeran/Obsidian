# Project Prioritization Framework

> *A simple system to decide what to build next using ICE scoring.*

## ICE Scoring Model

Score each factor from 1 (lowest) to 10 (highest). Multiply or add the scores to compare ideas.

| Factor | Description | 1 (Low) | 10 (High) |
|---|---|---|---|
| **Impact** | If this works, how big is the positive outcome? | Barely moves the needle | Game-changing outcome |
| **Confidence** | How sure am I that this will work as expected? | Pure guess, no data | High certainty, proven |
| **Ease** | How easy is this to execute? (Time/Money/Effort) | Months of hard work | Can be done this weekend |

## How to use

1. List potential projects or product ideas.
2. Quickly score them on Impact, Confidence, and Ease.
3. Calculate the total score.
4. Sort by highest score.
5. Apply a sanity check: *Does this align with my current goals?*
