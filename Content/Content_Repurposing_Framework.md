# Content Repurposing Framework

> Turn one core idea into an entire system of value.

## 1. The Core Idea (The Seed)
- Write the clearest, deepest version of your idea first.
- This is usually a long-form article, a deep-dive newsletter, or a comprehensive guide.
- Focus on the main insight, the frameworks, and the actionable takeaways.

## 2. Deconstruction (The Slices)
Break the core idea down into smaller, self-contained pieces.
- **Extract Frameworks:** Pull out the 1-2 frameworks or step-by-step processes.
- **Extract Stories:** Pull out the main example or case study.
- **Extract Controversial/Strong Opinions:** Find the punchiest 1-2 sentences.

## 3. Format Translation (The Matrix)

| Format | Goal | Action |
|---|---|---|
| **Twitter/X Thread** | High engagement, teach a process | Turn the main framework into a step-by-step thread. |
| **Short-form Video** (Reels/Shorts) | Top-of-funnel reach | Script a 60-second hook + 1 key takeaway + call to action. |
| **LinkedIn Post** | Professional networking, credibility | Share the core lesson with a professional anecdote or "hard lesson learned." |
| **Email Newsletter** | Deep connection, ownership | Share the full core idea with a personal intro. |
| **Visual/Carousel** | Saveability, shareability | Design 5-10 slides summarizing the main points visually. |

## 4. Scheduling & Distribution
- Don't post everything at once. Spread the repurposed assets out over 2-4 weeks.
- Link the short-form assets back to the original long-form core piece whenever possible to drive deep traffic.
